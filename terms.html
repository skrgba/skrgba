02Description of service

SKR GBA is an Android application that emulates the Nintendo Game Boy Advance handheld console using the open-source mGBA libretro core. The app allows users to load their own legally-obtained GBA ROM files and play them on Android devices, with a focus on the Solana Seeker.

The app uses the Solana blockchain to manage licensing: a one-time SOL payment serves as proof of license, verified on-chain. SKR GBA is not affiliated with Nintendo, Solana Labs, Solana Mobile, the mGBA project, or any wallet provider.

05Payment & fees

SKR GBA charges the following one-time on-chain fees, payable in SOL on the Solana mainnet-beta network:

  • App License — 0.1 SOL: Required to unlock core emulator access (load ROMs, save states, custom controls).
  • Anti-Cheat Fee — 0.2 SOL: Optional. Unlocks the cheat code entry feature (GameShark / Action Replay / Code Breaker). Not required to play any game. The price is deliberately set higher than the App License to discourage cheating.

How payments work

The app builds a standard SOL transfer transaction directly addressed to the developer's treasury wallet. You sign the transaction in your own Solana wallet app. Access is granted only after the transaction is confirmed and verified on-chain.
